# ds-study

Мой учебный репозиторий: путь от первого курса РТУ МИРЭА («Технологии ИИ и анализ данных») до стажировки в DS / ML / аналитике.

**Цель к весне 2028:** уверенные Python, алгоритмы, SQL и ML, чтобы пройти контест и интервью на стажировку.

## План

| Этап | Курс | Что даёт |
|---|---|---|
| 0 | «Поколение Python для продолжающих» (Stepik) | добить базу языка |
| 1 | **CS50P** | Python как следует: функции, исключения, тесты, ООП |
| 2 | **CS50x** (часть) | алгоритмы, память, структуры данных |
| 3 | **CS50 SQL** | запросы, JOIN, проектирование БД |
| 4 | **Kaggle Learn** | pandas, визуализация, ML-основы |
| 5 | **CS50AI** | поиск, вероятности, ML, нейросети |

Параллельно: задачи по алгоритмам дважды в неделю (LeetCode easy → medium) с разбором сложности и крайних случаев, и связь с линалом и матаном там, где она есть.

## Структура

```
python/       уроки по Python: задачи + тесты pytest
algorithms/   задачи по алгоритмам (LeetCode и др.)
sql/          запросы и схемы по CS50 SQL
ml/           ноутбуки и проекты Kaggle Learn / CS50AI
```

## Как работает урок

Каждый урок — отдельная папка, например `python/01_strings/`. В ней:

- `strings_tasks.py` — мой код (разминка, основная задача, задача со звёздочкой);
- `test_strings_tasks.py` — тесты pytest к этим задачам.

Имена файлов с тестами должны быть **уникальными во всём репозитории** (`test_strings_tasks.py`, а не просто `test_tasks.py`), иначе pytest не сможет их различить.

## Запуск тестов

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt

pytest                           # все тесты
pytest python/00_example         # тесты одного урока
pytest -k reverse                # тесты, в имени которых есть "reverse"
```

Тесты также запускаются автоматически на GitHub при каждом пуше (вкладка **Actions**).
