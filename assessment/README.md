# Входной тест

Практическая часть стартовой диагностики. Теория идёт в чате, а здесь лежит код.

| Файл | Что внутри |
|---|---|
| `python_assessment.py` | 10 задач: строки, словари, стек, хеш-таблица, бинпоиск, ДП, матрицы, класс |
| `sql_assessment.py` | 5 запросов к маленькой базе студентов и оценок |

Правила: пиши сам, без подсказок ИИ и без поиска готовых решений. Если не получается, оставь как есть и напиши, на чём застрял: это тоже результат. Время на задачу засекай примерно.

```bash
pytest assessment                                # всё
pytest assessment/test_python_assessment.py -k two_sum
```

Папки нет в `testpaths`, поэтому CI её не запускает и не краснеет от нерешённых задач.
