# Алгоритмы

Задачи по алгоритмам дважды в неделю: LeetCode easy → medium, позже темы из CS50x.

Одна задача — один файл решения и один файл тестов, например `two_sum.py` и `test_two_sum.py`.
В начале файла решения — комментарий со ссылкой на задачу, сложностью по времени и памяти и крайними случаями.
